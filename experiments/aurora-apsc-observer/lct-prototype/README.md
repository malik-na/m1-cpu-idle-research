# Disabled APSC timestamp helper prototype

**Offline source and validation only, 4 October 2026. Do not load this module or read `+0x38` under the current evidence.** The [design review](DESIGN.md) records the proposed gates and limitations. This source is a default-disabled prototype for the T8103 ABI 3 kernel, not a live calibration or an implementation of the [prospective command-BUSY pilot](../WFI-APSC-CMD-BUSY-CALIBRATION-PROTOCOL.md). Its three compile-time gates are zero; the reviewed default object has no mapping or kretprobe dependency, and no register access was performed. Even the known-register command-only branch needs a separately reviewed implementation and protocol before use.

These are **build and identity checks**, not live register safety or experimental correctness evidence. The module binary and full private build tree are not publication artifacts.

A [separate offline review](REVIEW.md) found no critical issue preventing **publication in this disabled state**, after mapping-error and timestamp-order fixes. That review did not approve live loading.
